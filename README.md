# Customer Shopping Behavior Analysis

## Project Overview

This project analyzes customer shopping behavior using Python, SQL, and Power BI. The goal is to identify purchasing patterns, customer preferences, and business insights that can help improve decision-making and customer engagement.

## Objectives

* Analyze customer purchase behavior
* Identify trends and patterns in shopping activity
* Perform data cleaning and preprocessing
* Create visualizations and dashboards
* Generate actionable business insights

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* SQL
* Power BI
* Jupyter Notebook

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Business Insights
6. Dashboard Creation

## Key Insights

* Identified customer purchasing trends
* Analyzed product preferences across customer groups
* Evaluated spending behavior and sales patterns
* Created visual reports for decision-making
